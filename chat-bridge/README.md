# Мост «Производственный учёт УТК → LocalChat»

Отдельный маленький сервис: следит за журналом действий учёта и шлёт
важные события сообщением в группу чата. Ничего не меняет ни в учёте,
ни в чате — можно выключить в любой момент.

## Что попадает в чат

- 🚨 массовый дефект
- 📦 изделие помещено в изолятор
- 🚚 отгрузка 
- ⚠️ обход техпроцесса

## Настройка 

1. В чате зарегистрируйте бота: обычный пользователь, логин `uchet_bot`.
2. Создайте группу (например «Уведомления») и добавьте туда бота
   (или пусть бот сам создаст группу — тогда пригласите туда людей).
3. `copy .env.example .env` и заполните пароль бота и название группы.
4. Проверка: `start-chat-bridge.bat test` — в группе появится
   «Проверка связи». Запуск: `start-chat-bridge.bat`.

Требуется только Node.js. Зависимостей нет.

## Как это работает

Каждые POLL_SECONDS секунд мост читает `/api/logs` учёта, находит новые
записи нужных типов и отправляет их в группу через обычный API чата
(`POST /api/groups/:id/messages`) от имени бота. Отправленные записи
запоминаются в `.bridge-state.json` — повторов не будет, старые события не шлются.
